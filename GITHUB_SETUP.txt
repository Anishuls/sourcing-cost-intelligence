🔐 GITHUB AUTHENTICATION (If prompted)
═══════════════════════════════════════════════════════════════════════════

If Git asks for credentials when pushing, use a Personal Access Token:

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token" (classic)
3. Give it a name: "Git CLI"
4. Select scopes:
   ☑ repo (full control of private repositories)
5. Click "Generate token"
6. Copy the token (appears once!)
7. When Git prompts for password, paste the token instead

GitHub also supports SSH keys - this is more secure for repeated use:
1. Generate SSH key: ssh-keygen -t ed25519
2. Add to GitHub: https://github.com/settings/ssh/new
3. Configure Git to use SSH instead of HTTPS

🔄 FUTURE UPDATES: AFTER INITIAL PUSH
═══════════════════════════════════════════════════════════════════════════

When you make changes locally and want to push updates:

1. Make your changes to index.html or other files
2. Stage the changes:
   git add .
   
3. Commit with a message:
   git commit -m "[feat] Your feature description"
   
4. Push to GitHub:
   git push

That's it! The changes automatically appear on GitHub.

Good commit message examples:
  git commit -m "[feat] Add PDF export functionality"
  git commit -m "[fix] Fix column detection for Excel files"
  git commit -m "[docs] Update README with new features"
  git commit -m "[refactor] Improve data parsing performance"

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: "fatal: 'origin' does not appear to be a 'git' repository"
Solution: Make sure you're in the right directory:
  cd C:\Users\Anish\Downloads\sourcing-cost-intelligence

Problem: "Permission denied (publickey)" or authentication fails
Solution: Use HTTPS instead of SSH, or generate Personal Access Token

Problem: "Everything up-to-date" but files not showing on GitHub
Solution: Make sure you're pushing the main branch:
  git push -u origin main

Problem: Want to undo the last commit
Solution: 
  git reset --soft HEAD~1
  (Changes still in staging, can recommit)
