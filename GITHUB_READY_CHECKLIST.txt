🔐 GITHUB AUTHENTICATION
───────────────────────────────────────────────────────────────────────────────

If Git asks for credentials when pushing:

Option A: Personal Access Token (Recommended for HTTPS)
  1. Go to: https://github.com/settings/tokens
  2. Click "Generate new token" (classic)
  3. Scopes: Check "repo"
  4. Generate and copy the token
  5. Use token as password when Git prompts

Option B: SSH Keys (More secure for repeated use)
  1. Generate: ssh-keygen -t ed25519
  2. Add to GitHub: https://github.com/settings/ssh/new
  3. Git will use SSH automatically

Q: Can I add more files to the repository?
A: Yes! Just add them, git add ., git commit -m "message", git push

Q: Can I rename the repository?
A: Yes! On GitHub, go to Settings → Rename (update remote URL after)

Q: How do I add collaborators?
A: GitHub → Settings → Collaborators → Add people

Q: Can I make it private later?
A: Yes, Settings → Change visibility to Private

Q: How do I delete the repository?
A: GitHub → Settings → Danger zone → Delete this repository

Q: What if I mess up a commit?
A: git reset --soft HEAD~1 (keeps changes, undoes commit)

Q: How do I update my local repository from GitHub?
A: git pull

Q: Can I host the app online?

🆘 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Issue: "fatal: 'origin' does not appear to be a 'git' repository"
Fix: Make sure you're in the correct directory

Issue: "Permission denied (publickey)"
Fix: Use HTTPS instead of SSH, or generate Personal Access Token

Issue: "Everything up-to-date" but files not showing
Fix: Make sure you pushed the right branch (git push -u origin master)

Issue: Git asks for username/password repeatedly
Fix: Use Personal Access Token instead of password

Issue: Can't remember my GitHub password
Fix: Use "Forgot password" on GitHub login page
